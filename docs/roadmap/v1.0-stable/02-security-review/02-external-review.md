# Job: External review or audit

Version: v1.0 · Epic: 02 Security review · Status: planned · Depends on: 01

## Goal

An independent reading of the security-relevant code and deployment guidance, scoped to
authentication, authorization, data handling and the provider boundary.

## Tasks

- [ ] Scope document and a reviewer (a community security reviewer or a paid audit,
      decided by the owner).
- [ ] Fix or document every finding; publish a summary in `docs/security.md`.

## Acceptance criteria

- Review completed, no open high findings at tag time.
